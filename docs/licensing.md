# Licensing

FamilyFi is intended to be offered under an open-source license plus an alternative paid commercial license. The exact open-source license, commercial terms, copyright ownership, and contributor terms are **not chosen yet**.

Do not assume a default MIT/Apache license or that a generic DCO/CLA already grants commercial relicensing rights. Contribution terms must support offering contributed code under the intended commercial terms before the repository is made public.

Until that decision, the project remains private and `UNLICENSED`.
